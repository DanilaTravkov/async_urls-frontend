# Async URL Checker — Frontend

Frontend сервиса асинхронной проверки URL.

## Стек

- React и TypeScript;
- Vite;
- Tailwind CSS;
- shadcn/ui;
- Vitest и React Testing Library.

## Запуск

```powershell
pnpm.cmd install
pnpm.cmd run dev
```

## Проверки

```powershell
pnpm.cmd run lint
pnpm.cmd run typecheck
pnpm.cmd run test:run
pnpm.cmd run build
```
